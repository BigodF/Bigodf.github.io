multiprocessing 的创建进程的方式包括三种：
- fork。linux 的默认方式（python3.14 以后默认是 forkserver）。使用 os.fork()方法开启一个新的解释器进程。继承父进程的所有资源，和父进程等同。在 fork 多线程进程的时候，可能会有问题。
- forkserver。linux、windows 支持。首先 spawn 一个 server 进程，然后在利用 server 进程 fork 需要的进程，server 进程是单线程的（除非系统库、预先 import 的库包含 spawn 的线程）。
- spawn。mac 、windows 的默认方式。开启一个新的解释器进程，只继承 run 方法必须得父进程资源。启动过程会比 fork、forkserver 慢。

注意：
forkserver 创建的进程无法通过 ps 命令分别出来，pstree 命令会出现多个进程，也无法区分哪个是实际的执行线程。可以通过第三方库setproctitle给子进程设置 title，这样就能在 ps 命令中区分实际执行任务的进程了。

``` python 
setproctitle.setproctitle(proc_title)
```

## 如何优雅的退出进程？

设想一下这样的场景：你有一个在线的进程，这个进程不断地从队列中读取数据，经过一系列处理后，发送给下游队列。如果你需要更新代码、或者迁移机器，需要 kill 当前进程，你直接使用 kill 命令，这时候一些数据正在处理中，直接 kill 会导致这些数据已经从队列中取出、但是没有完整的处理完成并发送给下游。这些数据就丢失了。那么如何才能优雅的 kill 进程呢？

linux 下， kill 命令会给进程发送一个 signal，在进程里可以指定这个 signal 的处理方式，我们可以通过制定这个 signal 的处理方式，来达到优雅地退出进程的目的。

```python fold
import signal
import multiprocessing as mp

e = mp.Event()
def signal_handle(signum, frame): # signal handle函数的固定形参，不需改动
    logger.info(signum)
    e.set() # 当进程收到TERM信号时，e会被set，只需要在实际的进程中检测这个e的状态，就可以优雅的退出进程了。比如在每次循环的时候检测e的状态。
signal.signal(signal.SIGTERM, signal_handle) # 制定TERM signal的处理方式

while True:
    if e.is_set():
        break
    item = input()
    process(item)
    output(item)

```

## 多进程示例

python 中开启多线程的方式：
1. from multiprocessing import Process
2. from concurrent.futures import ProcessPoolExecutor

ProcessPoolExecutor 是 Process 的高层抽象实现，Process 更底层。

```python fold
import multiprocessing, time
from concurrent.futures import ProcessPoolExecutor
from multiprocessing import Manager, Process

def con(pid, q):
    res = []
    print(f'pid: {pid}, {id(q)}')
    while True:
        time.sleep(0.5)
        i = q.get()
        print(f'pid: {pid}, {i}')
        res.append(i)
        q.task_done()
        if i == None:
            break
    return res


def pro(q):
    print(f'pid: {id(q)}')
    for i in range(10):
        time.sleep(0.5)
        q.put(i)
    
    # 添加生产结束标志
    q.put(None)
    q.put(None)
    
    return None


q = Manager().JoinableQueue() # 进程间通信队列

# ProcessPoolExecutor方式
with ProcessPoolExecutor(3) as pool:
    p = pool.submit(
        pro,
        q
    )
    proc_list.append(p)
    for i in range(2):
        p = pool.submit(
            con,
            i,
            q,
        )
        proc_list.append(p)
    res = [p.result() for p in proc_list] # 获取每个任务的结果


# Process方式
proc_list = [
    Process(target=pro, args=(q, )),
    Process(target=con, args=(0, q)),
    Process(target=con, args=(1, q)),
]
for p in proc_list:
    p.start()
for p in proc_list:
    p.join()
    

```
