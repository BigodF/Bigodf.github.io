牛顿法：
1. 对于可导函数 $g(x)$ 来说，需要求其零点。
2. 先随机取一点 $(x_0, g(x_0))$ 。
3. 构造在此处的直线，直线斜率和此处梯度相同 $f(x) = g'(x_0) (x - x_0) + g(x_0)$ 。
4. 直线零点为 $x_1 = x_0 - \frac{g(x_0)}{g'(x_0)}$ 。
5. 不断迭代，直到精度满足要求。

```python fold
def sqrt_newton(a, eps=1e-10):
    x = a  # 初始猜测
    while True:
        x_next = 0.5 * (x + a / x)
        if abs(x_next - x) < eps:
            return x_next
        x = x_next

# 使用
print(sqrt_newton(2))   # 输出 1.4142135623730951
```
